# Assets

README visuals. `home.png`, `retrieval.png` and `report1.png` are captured from
the deployed demo at https://researchpilot.peng1z.workers.dev/ and should be
recaptured whenever the interface changes -- a stale screenshot showing an empty
state is worse than none, because it advertises behaviour the app no longer has.

Do not store secrets, API keys, or private screenshots in this folder.
